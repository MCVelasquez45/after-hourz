# Lowrider Prototype Reference Pool — PROVENANCE

**Status:** PROTOTYPE REFERENCE ONLY. These are external stock photos used for
art-direction / composition studies inside `/design-lab/*`. They are **NOT**
After Hourz / Anthony Montoya completed work and must never be presented as such.

**Culture:** Authentic SoCal lowrider culture (candy paint, gold/chrome wire wheels,
hydraulics, cruising, car-club/meet, gold-leaf + pinstripe). NorCal / QUINCY /
Northern-California geography was actively rejected during curation (Alcatraz,
Hyde St. Pier, Fisherman's Wharf, 530 area code, etc. all excluded).

**Source & License:** Unsplash. Unsplash License = free for commercial and
non-commercial use, no permission needed (attribution appreciated, not required).
Source URL pattern: https://unsplash.com/photos/<slug> (slug = trailing token of filename).

**Curation:** Each frame was visually inspected and confirmed to be a genuine
custom lowrider / classic craft on-thesis. Rejected: supercars, EVs, JDM/drift,
lead-sled kustoms, RGB-bling show pieces, foreign-plate/foreign-setting cars,
and NorCal geography.

Any per-image facts about the specific vehicle/owner are CLIENT INPUT REQUIRED.
